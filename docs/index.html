어떤 글자를 세나요?

  • PDF에서 추출되는 텍스트를 셉니다. 한글과 결합 문자는 화면상 한 글자 단위로 계산합니다.
  • 공백 포함에는 추출된 띄어쓰기·탭이 포함됩니다. 줄바꿈과 페이지 구분은 두 결과 모두에서 제외합니다.
  • 머리말·꼬리말·숨겨진 텍스트도 추출되면 포함됩니다. PDF의 글꼴·텍스트 저장 방식에 따라 원본 편집기의 글자 수와 다를 수 있습니다.
  • 스캔 이미지의 글자는 인식하지 않습니다. OCR이 필요한 페이지와 암호가 설정된 PDF는 안내합니다.
  • 다른 파일 선택·지우기·페이지 닫기 시 이 도구의 파일 참조와 결과가 제거됩니다.
