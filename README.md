# PDF 글자 수

수학 수업 허브의 `public/pdf-counter/`에 포함된 브라우저 전용 도구입니다. 허브의 ‘내 프로그램 → PDF 글자 수’ 카드에서 엽니다.

독립 실행: 이 폴더에서 `npm start` 후 http://127.0.0.1:4174/pdf-counter/ 접속. 서버는 127.0.0.1에만 바인딩하며 GET/HEAD 정적 파일 제공만 허용합니다. PDF와 결과를 받거나 저장하는 엔드포인트는 없습니다. 인터넷 연결 없이 동작합니다. 최신 Edge/Chrome을 사용하세요.

PDF.js 6.4.299의 공식 npm 배포를 버전 고정했습니다. `npm install --ignore-scripts --omit=optional` 후 `node sync-vendor.mjs`로 번들·워커·CMap·폰트·WASM·Apache-2.0 라이선스를 허브에 복사합니다. 런타임 CDN·분석 SDK·원격 OCR은 없습니다. 선택적 네이티브 canvas 의존성과 설치 스크립트는 사용하지 않습니다. 잠금 파일의 무결성 해시를 유지하세요.

PDF 바이트는 워커에 전달되고, 추출 텍스트는 페이지 단위로 집계 후 참조를 해제합니다. 원문·파일 이름·추출 텍스트를 화면이나 로그에 출력하지 않고 파일·결과를 영속 저장하지 않습니다. 완료·실패·취소 시 PDF 워커를 종료합니다. 지우기·다른 파일 선택·페이지 닫기 시 결과도 제거합니다. JavaScript의 메모리 해제는 가비지 수집 시점에 따르며 보안 삭제를 보장하지 않습니다.

한글 NFC 정규화 후 Intl.Segmenter의 grapheme 단위로 셉니다. 줄바꿈은 제외하고 추출 문자열의 공백·탭만 공백 포함 값에 반영합니다. 텍스트 항목 사이에 임의의 공백을 추가하지 않습니다. 머리말·숨은 텍스트가 포함될 수 있고 원본 편집기와 값이 다를 수 있습니다. 이미지 OCR·암호 PDF는 지원하지 않습니다. 50 MiB·1,000페이지·추출 텍스트 500만 UTF-16 단위·90초 제한을 적용합니다.

검증: `npm test`. 허브 빌드 시 도구와 vendor 자산이 public에서 복사됩니다. 서비스 워커는 정적 앱 자산만 캐시해야 하며 사용자 PDF나 결과를 캐시하는 코드를 추가하지 마세요.
